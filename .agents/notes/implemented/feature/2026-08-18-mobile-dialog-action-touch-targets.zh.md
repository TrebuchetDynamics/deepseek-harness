# Agent Note: 移动端对话框操作触控目标尺寸

Status: implemented

[English](2026-08-18-mobile-dialog-action-touch-targets.md) | 中文

## 问题

首次运行的引导模态框（欢迎通知与凭据对话框）将操作按钮——继续、稍后配置、保存并继续——渲染为 36px 高，低于 WCAG 2.5.8 的 44px 触控下限，与此前移动端触控目标改进修复的控制栏与输入框控件处于同一水平。对话框操作是新安装用户最先点击的目标。

## 决策

由 ui-primitives 的共享 Button 组件负责修复：标准操作形态（`.md`，36px）在与布局层侧边栏自动折叠一致的窄屏断点（`max-width: 1023px`）下增长到 44px。紧凑的 `.sm` 形态保持不变，供密集行使用。一条媒体查询范围内的规则即可覆盖所有对话框操作——引导、凭据以及未来的对话框——规则落在共享所有者上，而非逐模态覆盖。

## 备选方案

**仅将提升范围限定在引导模态框。** 已否决：该下限适用于触控设备上的所有对话框操作，逐模态覆盖会造成重复并产生漂移。

## 影响

所有标准对话框操作按钮在窄视口下达到 44px；桌面端保持 36px 形态（受媒体查询限定）。button-styles 客户端 spec 固定了该规则及未改变的桌面高度。
