# Agent Note: 移动端安全区内边距

Status: implemented

[English](2026-08-18-mobile-safe-area-insets.md) | 中文

## 问题

shell 用固定像素为侧边栏控制栏与停靠式输入框设置内边距。在独立／PWA 场景（已随包发布 manifest）下，刘海屏设备的状态栏与 Home 指示条会与控制栏顶部的控件及输入框的底部边缘重叠；此前整个客户端的移动端改进都没有任何安全区处理。

## 决策

在内容级内边距中加入 `env(safe-area-inset-*)`：侧边栏控制栏与展开抽屉在现有内边距上叠加顶部与底部安全区（`calc(... + env(safe-area-inset-top/bottom))`），输入框的底部内边距加入底部安全区。在浏览器标签页内安全区为 0，这些规则在那里是无操作；在独立模式下，控制栏与输入框会避开设备界面元素。shell overlay 层与拖拽手柄不受影响（它们不是贴边内容的 chrome）。

## 备选方案

**用安全区内边距包裹整个 frame。** 已否决：列的填充色应延伸进安全区（满幅背景），只有内容才需要贴边内边距——给 frame 加内边距会让背景色在屏幕边缘留下空白带。

## 影响

在独立模式下，控制栏、抽屉与停靠式输入框避开刘海屏设备的界面元素；浏览器标签页内无任何变化。sidebar-styles 与 mobile-touch-targets 客户端 spec 固定了这些内边距值，包括移动端控制栏媒体查询内的值。
